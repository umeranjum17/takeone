Third tester build: `takeone doctor` no longer reports a failed install when only optional checks are missing.

## Install

Needs Node.js 22.19 or newer and ffmpeg on PATH.

```sh
npm install -g --allow-remote=all https://github.com/umeranjum17/takeone/releases/latest/download/takeone.tgz
takeone doctor
```

## Fixed

- `takeone doctor` exits 0 when only optional checks are false, such as no AI key set. It exits 1 only when a check every capture route needs fails: ffmpeg, the state dir or the takes root.
- Each doctor row names the capture route that needs it in `needed_by`, so you can see which rows matter for the route you are using.

## Known issues

- Desktop recording works on Linux only (Wayland with Hyprland). macOS desktop capture is not supported yet.
- iOS recording works with the iOS Simulator only, not a real iPhone.
- Videos are silent: there is no audio track.
