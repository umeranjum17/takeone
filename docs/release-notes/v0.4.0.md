# TakeOne 0.4.0

Install TakeOne with `npm install -g takeone-axi`.

- Motion films use the HyperFrames engine by default; install its pinned runtime with `takeone motion install-hyperframes`.
- `takeone make --target-score` and `--max-rounds` score films and iterate within a bounded number of rounds. The default judge is Haiku.
- Launch-film camera motion and cut-ready scene exports make motion films easier to review and edit.
