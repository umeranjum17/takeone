# TakeOne 0.5.1

Install TakeOne with `npm install -g takeone-axi`, or from this release:

```
npm install -g --allow-remote=all https://github.com/umeranjum17/takeone/releases/latest/download/takeone.tgz
takeone doctor
```

0.5.1 is the first build of the 0.5 line on npm. The 0.5.0 tag run failed on a build error and never published, so everything in the 0.5.0 notes ships here too, plus the changes below.

## What is new since 0.5.0

- **Launch reels.** Five more motion patterns and the launch, feature, social and compare recipes, in landscape and portrait. A reflowing bento launch reel is made from one screen and a pitch.
- **Model-made segments.** Segments the model makes are recorded beside the real screen capture.
- **Faster preview.** The camera solve is cached, so a repeat preview or render skips it. Preview shows cold and warm timing, and captioned-take band rows are fixed.
- **Look.** The stage is a near-black field with a soft accent glow that does not band.
- **Film gates.** Motion films are gated on frozen time and audio loudness; motion-video-kit is attributed.
- **Release.** The npm publish job gates on build and typecheck, not the full suite.

## Test these first

1. `npm install -g takeone-axi` then `takeone --version` prints 0.5.1, and `takeone doctor` passes.
2. `takeone motion <screenshot> --recipe launch --pitch "..."` and check the bento reel in landscape and portrait.
3. Run the same preview twice and confirm the second is faster (cached camera solve).
