# TakeOne 0.5.2

Install TakeOne with `npm install -g takeone-axi`, or from this release:

```
npm install -g --allow-remote=all https://github.com/umeranjum17/takeone/releases/latest/download/takeone.tgz
takeone doctor
```

0.5.2 is the first build of the 0.5 line on npm. The 0.5.0 tag run failed on a build error, and the 0.5.1 npm publish was rejected because `package.json` had no `repository` field, which provenance checks require. This release adds it and changes nothing else, so everything in the 0.5.0 and 0.5.1 notes ships here.

## What is new since 0.5.1

- **npm publish.** `package.json` now names the repository, so the provenance-signed publish to npm is accepted.

## Test these first

1. `npm install -g takeone-axi` then `takeone --version` prints 0.5.2, and `takeone doctor` passes.
2. `npm view takeone-axi repository.url` prints the GitHub repository.
