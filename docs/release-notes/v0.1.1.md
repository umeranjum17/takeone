Second tester build: the install, render and recording fixes from the first tester pass.

## Install

Needs Node.js 22.19 or newer and ffmpeg on PATH.

```sh
npm install -g --allow-remote=all https://github.com/umeranjum17/takeone/releases/latest/download/takeone.tgz
takeone doctor
```

## Fixed

- An isolated install no longer reads the host keyring: set `TAKEONE_NO_KEYRING=1` and takeone stays off the OS keyring entirely.
- Films render as parallel time segments instead of one long pass, and rendering no longer hangs on sources with no zoom headroom (for example a 1080p source in a 4:5 export).
- The text guard now also covers recordings that end before the take does, so the last frame is still checked.
- `take.json` records takeone's real package version, so takes made with different builds are distinguishable.
- README and guide close the Linux, iOS Simulator and Android install gaps from the first pass.

## Known issues

- Desktop recording works on Linux only (Wayland with Hyprland). macOS desktop capture is not supported yet.
- iOS recording works with the iOS Simulator only, not a real iPhone.
- Videos are silent: there is no audio track.
